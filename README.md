# Measurement Guide — Translations

Translations of the **Ioanna Custom Sewing** measurement guide, plus simple HTML mockups for each language.

> **Private repository.** The source text belongs to Ioanna Custom Sewing, LLC and is not ours to publish openly.

## Source and credits

- **Source:** Ioanna Custom Sewing, LLC — Measurement Guide, <https://orthodox-attire.com/measurement-guide>.
  All rights in the source text belong to Ioanna Custom Sewing, LLC.
- **Translator:** Rosetta Stone (Spanish, Russian, Romanian, Arabic, Greek).
- The English file is a faithful transcription of the original page (rebuilt 2026-10-18), with the original numbering and wording kept as published.

Open `index.html` in a browser to view the mockups. `ar.html` uses `<html lang="ar" dir="rtl">`.

## Numbering

The original guide's numbering is kept exactly, including the repeated numbers: there are two items numbered **1** (Rasso Length, Cassock Length) and three numbered **5** (Arm Length, Rasso Sleeve Length, Cassock Sleeve Length). Every language has the same 18 items numbered 1–15.

## Translator notes (Rosetta Stone)

- **Arabic, item 15:** the Arabic term used for the *skoufia* (the clergy/monastic cap) varies by parish; check the term your community uses.
- **Greek, item 4:** "yoke" is rendered **Φάρδος ώμων**.
